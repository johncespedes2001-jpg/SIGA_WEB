# Páginas HTML de SIGA

Cada carpeta corresponde a un rol institucional. Los archivos HTML declaran el rol y la página mediante los atributos `data-role` y `data-page` del elemento `body`. El contenido visual compartido se genera desde `public/script.js` y todos los estilos se encuentran en `public/styles.css`.

- `administrador`: 6 páginas.
- `docente`: 5 páginas.
- `coordinador`: 5 páginas.
- `tutor`: 5 páginas.
- `padre`: 5 páginas.
- `vigilante`: 4 páginas.
- `estudiante`: 5 páginas.

La entrada principal es `public/index.html`, que contiene la selección de rol y el formulario de inicio de sesión.
